# Portfolio Website Template

A modern, responsive single-page portfolio website template with a sleek dark UI design. This project is built using pure HTML and CSS, making it lightweight, customizable, and easy to deploy.

## Project Overview

This is a static portfolio website featuring:
- A clean header with navigation and call-to-action
- Hero section with bold typography
- "See It in Action" section with an image preview
- User statistics section highlighting key metrics
- Customer testimonials/reviews with star ratings
- Subscription/CTA section
- Contact form
- Footer with links and copyright

The design uses a dark theme with modern aesthetics, ideal for personal portfolios, agencies, or product landing pages.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Google Fonts Integration**: Uses "Open Sans" for clean, readable typography
- **Font Awesome Icons**: Includes star icons for review ratings
- **External Assets**: Includes placeholder images and buttons styled via CSS
- **Accessibility Ready**: Proper semantic HTML structure and alt attributes

## Technologies Used

- HTML5
- CSS3 (external stylesheet: `styles/style.css`)
- Google Fonts (Open Sans)
- Font Awesome (via CDN)
